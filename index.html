Sync with GitHub

Saving to

Keep your data in a private GitHub repository so your phone and laptop stay in sync. Your token is stored only in this browser.

How to set it up (2 minutes, one time)
  1. Create a new private repository, e.g. cal-tracker-data: github.com/new. Leave it empty.
  2. Create a token: Settings → Fine-grained tokens → Generate new token.
    • Expiration: your choice. When it expires, make a new one and paste it in here.
    • Repository access: Only select repositories → pick your data repo.
    • Permissions → Repository permissions → Contents: Read and write.
  3. Copy the token (starts with github_pat_) and paste it below. Do the same on each device.

COROS workouts (via Strava)

Automatically adds the calories from your COROS workouts. COROS sends each workout to Strava, and an hourly job in your private data repo copies them here.

Set up (one time, about 10 minutes)

First connect Sync with GitHub above. The importer runs in that private repo.

  1. COROS → Strava. In the COROS app, open Profile → Settings → Third-party apps (or Connected apps), choose Strava and connect it. New workouts will then upload to Strava automatically.
  2. Create a Strava API app at strava.com/settings/api. Any name and category are fine. Set Website to and Authorization Callback Domain to (tap Edit on that page to change it).
    Ignore the “Your Access Token” and “Your Refresh Token” shown on Strava's page. They only have read scope and can't see your workouts. Step 4 gets the right one.
  3. Authorise. Copy the Client ID (the number in the “Client ID” row) here, then tap the button and allow access, keeping “View data about your private activities” ticked.
  4. Get your refresh token. This step unlocks after you authorise.

    The secret is sent straight to Strava and not saved here.
